# 1.0.0 业务验收矩阵

发布验收使用临时 SQLite 数据库和脱敏数据，通过 Tauri 公开命令层执行，不连接真实税局、银行或电子发票平台。

运行命令：

```bash
npm run verify:release-acceptance
```

## 覆盖范围

验收矩阵覆盖以下会计制度：

- 企业会计准则（`enterprise`）
- 小企业会计准则（`small_enterprise`）
- 民间非营利组织会计制度（`non_profit`）
- 农民专业合作社会计制度（`cooperative`）

每个账套执行同一条可审计业务链：

1. 初始化账套、启用账期、法定科目和报表模板。
2. 在临时数据库暂存脱敏发票和银行流水采集结果；夹具适配器保持未授权、禁用状态，不发起外部网络请求。
3. 通过正式的人工复核命令导入发票及明细、银行流水，再生成借贷平衡凭证。
4. 关联发票、流水和凭证，审核后核对科目余额。
5. 配置期末结转规则，完成结账，并验证结账后禁止写入。
6. 生成总账、明细账、法定资产负债表和损益类报表，验证业务来源、会计制度、模板和平衡关系。
7. 生成申报取数快照并完成本地确认；不模拟未经授权的税局提交。
8. 执行反结账、反审核、重新审核和红冲。
9. 核对业务操作日志和凭证审计日志。

实现位于 `src-tauri/src/release_acceptance.rs`，桌面构建 CI 会单独运行该矩阵，并在随后执行完整 Rust 测试套件。
