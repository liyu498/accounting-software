# 1.0.0 容量与性能验收

性能发布门禁使用临时 SQLite 数据库和脱敏数据，单线程独立运行：

```bash
npm run verify:release-performance
```

## 验收规模

- 大账套：一次导入 10,000 张、20,000 条分录的凭证数据。
- 跨年度：数据均匀覆盖 2024 至 2026 年共 36 个连续账期。
- 多客户并发：4 个完整账套各保存 1,500 张凭证，并发执行带分录的分页查询。
- 导出与报表：导出大账套全部凭证，计算试算平衡表、资产负债表和利润表。

## 发布阈值

| 操作 | 上限 |
| --- | ---: |
| 10,000 张凭证导入 | 60 秒 |
| 深页分页查询 | 5 秒 |
| 三张核心报表合计 | 10 秒 |
| 10,000 张凭证 Excel 导出 | 30 秒 |
| 4 个客户账套并发分页查询 | 10 秒 |

时间上限用于发现数量级退化，不作为微基准。测试同时核对数据数量、跨年度账期连续性、借贷平衡、导出文件内容和客户数据隔离，避免只测时间但没有验证结果正确性。

性能测试在普通 `cargo test` 中标记为忽略，防止与其他测试并行争用 CPU 和 SQLite；桌面构建 CI 会通过独立命令单线程执行该门禁。
