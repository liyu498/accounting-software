# 1.0.0 恢复与升级演练

恢复发布门禁覆盖 schema v15 升级、受控恢复、损坏隔离和事务回滚。运行命令：

```bash
npm run verify:release-recovery
```

## 演练内容

1. 从旧结构升级到最新迁移版本，核对既有业务数据仍然存在。
2. 构造真实 schema v14 快照，通过公开命令完成校验和恢复安排。
3. 在安排恢复时生成恢复前安全快照，并核对其中保留当前数据库内容。
4. 模拟应用重启，在数据库连接建立前替换快照，再自动升级到 schema v15。
5. 核对 v15 表、旧账套数据、恢复标记和完成恢复审计记录。
6. 验证损坏快照被隔离，且不会覆盖当前数据库。
7. 验证任一迁移语句失败时，当前迁移创建的对象和迁移历史全部回滚。

演练只操作系统临时目录中的 SQLite 数据库，不接触用户实际数据。桌面构建 CI 会单独运行该门禁，并在随后执行完整 Rust 测试套件。
